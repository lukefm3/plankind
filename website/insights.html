How it works

A reusable automation pattern.

GitHub Actions runs the R pipeline every day. The script downloads OpenFEMA data, standardizes publication fields, performs validation checks, and publishes clean data files with the website.

The same structure can support public indicators, program monitoring, scheduled client reports, maps, forecasts, or recurring policy analysis.
