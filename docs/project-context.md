# PlanKind project context

PlanKind is a consulting and research practice helping nonprofits, government
agencies, public health organizations, and other mission-driven organizations
make better decisions through evidence, analysis, planning, and implementation.

## Mission

Help organizations make better decisions through evidence-based planning and
practical implementation.

## Motto

Grounded in evidence. Focused on impact.

## Development principles

1. Prefer maintainability over cleverness.
2. Automate repetitive work.
3. Build modular systems.
4. Separate raw data, processed data, and code.
5. Document major functions and workflows.
6. Make systems reproducible.
7. Connect technical decisions to better client outcomes.
